# Image Portfolio Project

This project is an image portfolio website that showcases various aerial photography works. It is built using React and TypeScript, and utilizes Vite as the build tool.

## Project Structure

```
image-portfolio
├── src
│   ├── components
│   │   ├── ContactSection.tsx
│   │   └── PortfolioGallery.tsx
│   ├── data
│   │   └── portfolio.ts
│   ├── pages
│   │   └── Portfolio.tsx
│   ├── styles
│   │   └── index.css
│   └── main.tsx
├── public
│   └── img
├── package.json
├── tsconfig.json
├── vite.config.ts
└── README.md
```

## Features

- **Portfolio Gallery**: Displays a grid of images from the portfolio, allowing users to view and interact with the images.
- **Contact Section**: Provides a contact form or information for users to reach out.
- **Responsive Design**: The layout adapts to different screen sizes for optimal viewing on both desktop and mobile devices.

## Setup Instructions

1. Clone the repository:
   ```
   git clone <repository-url>
   ```

2. Navigate to the project directory:
   ```
   cd image-portfolio
   ```

3. Install the dependencies:
   ```
   npm install
   ```

4. Start the development server:
   ```
   npm run dev
   ```

5. Open your browser and go to `http://localhost:3000` to view the application.

## Usage

- The main page of the portfolio can be accessed through the `/Portfolio` route.
- Users can view images in the gallery and interact with the contact section for inquiries.
